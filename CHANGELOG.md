# Changelog

## 0.1.0 · 25 October 2026

Initial public research release.

- Real Stim rotated surface-code circuits at distances 3, 5 and 7; standard and
  correlated PyMatching on identical circuit-level test shots.
- Original FrameNet residual model, 14 trained checkpoints, ablations, three
  primary initialization seeds and an unsuccessful full-map follow-up.
- 1.12 million independent test shots, 322 result rows, 406 paired comparisons,
  confidence intervals and complete CPU latency accounting.
- Live local lattice/space-time playground, graph correction certificates,
  exact replay examples, an eight-page report and reusable data.
- Public-release polish adds a visual README, evidence overview, citation and
  package metadata, portable Linux/macOS CI, and fail-closed verification of
  every file declared in the release manifest. A portable read-only audit
  reconciles every reported row and paired comparison. Future follow-up runs
  now retain their executed source and raw-prediction hashes at creation.
  Primary training source, learned weights
  and recorded numerical results are unchanged by publication polish.

The original scientific execution records describe the pre-publication local
study. Current CI results are attached to GitHub commits. No external-paper
replication, neural superiority, hardware result or hosted interactive service
is claimed.
