03

What the system actually learns.

01 / SIMULATE

Build a noisy history.

Stim simulates repeated stabilizer measurements in a rotated surface code. A detector event marks a change between expected measurement parities. Data and measurement errors both leave patterns across space and time.

02 / INFER

Learn the missing logical bit.

The compact neural model reads the syndrome history and matching context. It predicts whether the classical decoder's logical result needs a flip. This is a learned post-decoding correction, distinct from an AI pre-decoder that removes local faults.

03 / VERIFY

Test against hidden truth.

All decoders see the same syndrome. Only the evaluator sees Stim's true logical observable. Separate random seeds, held-out noise settings, ablations and strong matching baselines expose both improvements and failures.

A valid correction can still fail logically.

Many error patterns produce the same detector events. A correction can cancel every visible event yet differ from the actual fault by a logical operator. That is why syndrome consistency and logical success are shown separately.
