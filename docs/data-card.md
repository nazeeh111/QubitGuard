# Dataset card

All retained data are synthetic stabilizer-circuit experiments generated by
Stim 1.16.0, not quantum hardware measurements. Each file is a reusable NPZ plus
JSON provenance and exact `.stim` / `.dem` source.

- `dets`: one binary detector-event vector per independent shot.
- `truth`: final single logical-observable flip. Used only for training/scoring.
- `standard`, `correlated`: predictions from both true-noise-model PyMatching
  decoders, with correlation flags enabled during graph construction and
  correlated inference.
- `context`: inference-available features, in order: standard prediction,
  correlated prediction, disagreement, syndrome density, nominal p/0.01.

Circuit: `surface_code:rotated_memory_x`, distance in {3,5,7}, rounds=distance.
Uniform profile enables all four Stim generator noise channels at nominal p:
after-Clifford depolarization, before-round data depolarization, before-measure
flip and after-reset flip. This is circuit-level stochastic Pauli noise with
two-qubit propagation/correlations; it is not a phenomenological-only model.

The held-out `biased` profile is explicitly measurement-heavy channel imbalance:
gate depolarization p, idle-data depolarization p/4, measurement/reset flips 2p.
It is neither Pauli-Z-biased noise nor leakage. Both matching baselines receive
its exact DEM. Neural models only trained on uniform profiles.

Training p: 0.003,0.007,0.012. Test p: 0.001,0.003,0.005,0.007,0.01,0.012,0.015.
Repeated p values use independent split streams. Test p=0.005/0.01 are unseen
interpolation values; 0.001/0.015 extrapolate outside the training range. There
are 20,000 independent test shots at each of 42 settings (840,000 total).
A 60,000-shot single-p d3 control reuses the p=0.007 training seed with a
different sampling shape. Its arrays are not an exact prefix of the mixed-p
component; treat their randomness as related rather than independently drawn.
This is not train/test contamination. Model initializations deliberately share datasets.

Seeds use SHA256(setting key + split), with disjoint high-bit namespaces for
train/validation/test. The JSON stores actual 64-bit seeds, package versions,
circuit hash, NPZ checksum and generator source fingerprint. Replay depends on
Stim version/platform and sampling call sequence. Retained NPZ bytes are the
authoritative durable samples; a seed alone is not a cross-platform guarantee.

No personal, hardware-device, external-model or licensed gated data are present.
Original synthetic data use the root MIT license. See the technical report for
counts of logical failures and the limits of low-noise estimates.
